A one-sentence pitch that convinces a friend who has never coded to let an AI agent build their first app idea on make.fun.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes exactly one sentence (143 characters) to `entry.txt` in the output directory: a pitch telling a friend that if they can explain their app idea to a friend, they can hand it to an AI agent on make.fun and have a working first version to try before dinner. No network, no dependencies, Python 3.13 standard library only; the same run always writes the same bytes.
